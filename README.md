# Bank Management System

A Python-based Bank Management System that allows users to create accounts, login, check balance, deposit money, withdraw money, and manage their bank accounts.

## Features

- Create Bank Account
- User Login
- Check Balance
- Deposit Money
- Withdraw Money
- Account Information
- Logout
- JSON-based Data Storage

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `main.py`.
